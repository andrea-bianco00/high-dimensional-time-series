# Data provenance and publication boundaries

Beijing: [UCI Beijing Multi-Site Air Quality](https://archive.ics.uci.edu/dataset/501/beijingmultisiteairqualitydata), CC BY 4.0; download from the source and cite the dataset creators. Raw station CSV files and archives are not included.

Taiwan AirBox: redistribution rights and sampling provenance of the 516-sensor university matrix have not been established. The raw matrix, original group archives, R scripts, and course slides are not included.

No license has yet been granted for this repository's original code. Rights for code coauthored by university group members must be established separately.
